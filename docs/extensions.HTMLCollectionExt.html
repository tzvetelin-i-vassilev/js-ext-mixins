Class: HTMLCollectionExt

extensions.HTMLCollectionExt

HTMLCollection extension

Methods

(static) fromHTML(html) → {HTMLCollection}

Parses html and hands back its top level elements, without the wrapper a container would add and without running anything - the markup goes through a template, where scripts stay inert.

The collection is live over the parsed fragment, as every HTMLCollection is: moving the elements out of it empties it as you go, so take a copy first when the loop moves them.

Parameters:
Name Type Description
html string

Markup to parse
Returns:

The top level elements of it

Type
HTMLCollection
Example
for (let element of [...HTMLCollection.fromHTML("<li>one</li><li>two</li>")])
    list.appendChild(element);
